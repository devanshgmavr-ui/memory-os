# MemoryOS

An agentic AI application with persistent memory capabilities.

## Overview

MemoryOS is an AI agent system that leverages:

- **CockroachDB** - Persistent memory layer for storing and retrieving context
- **Amazon Bedrock** - Powers the AI agent's reasoning and generation capabilities
- **AWS** - Cloud infrastructure for deployment
